# W drodze — Travel Journal

## Live Demo

[Zobacz działającą stronę]
(https://cz-czarek.github.io/journal-travel/#start)

Osobisty dziennik podróży stworzony jako mój pierwszy projekt webowy.

Projekt łączy własne zdjęcia i wspomnienia z podróży z praktyczną nauką HTML, CSS, JavaScriptu, GitHuba oraz pracy z narzędziami AI.

## O projekcie

„W drodze” powstało jako prosty pomysł na uporządkowanie części zdjęć z podróży.

W trakcie pracy projekt rozwinął się w interaktywną stronę internetową zawierającą galerie zdjęć, filtrowanie miejsc, pełnoekranowy podgląd fotografii oraz krótkie historie związane z każdą podróżą.

Aktualnie na stronie znajdują się:

- Cypr — Famagusta i Varosha
- Gruzja — Kutaisi
- Polska — Tatry
- Niemcy — Berlin
- Malta
- Włochy — Rzym

## Funkcje

- responsywny układ strony
- galerie zdjęć dla każdej podróży
- wybór głównego zdjęcia za pomocą miniaturek
- poziome przewijanie większej liczby miniaturek
- pełnoekranowy podgląd zdjęć
- nawigacja pomiędzy zdjęciami w trybie pełnoekranowym
- licznik aktualnie oglądanego zdjęcia
- obsługa klawiszy strzałek oraz ESC
- filtrowanie podróży według kategorii
- okna z pełnymi opisami podróży
- możliwość zamknięcia okien za pomocą przycisku, kliknięcia tła lub klawisza ESC

## Technologie

Projekt został wykonany bez frameworków i bibliotek frontendowych.

Użyte technologie:

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- GitHub Codespaces
